---

## 2. Теоретические сведения

Docker — это платформа для автоматизации развертывания и управления приложениями в средах с поддержкой контейнеризации. Docker позволяет упаковать приложение и все его зависимости в контейнер, который может быть запущен на любой системе с установленным Docker Engine.

Основными компонентами Docker являются:
- Docker Engine (демон и клиент),
- Docker images (образы),
- Docker containers (контейнеры),
- Docker Hub (реестр образов),
- Docker Compose (инструмент для управления несколькими контейнерами).

Контейнеризация позволяет упростить развертывание приложений, повысить переносимость и обеспечить единообразие окружений разработки и эксплуатации.

## 3. Ход выполнения работы

### 3.1 Установка Docker Engine и docker-compose

В операционной системе Ubuntu был установлен Docker Engine Community Edition и docker-compose.  
После установки была выполнена проверка работоспособности сервиса Docker.

### 3.2 Клонирование репозитория

Для выполнения лабораторной работы был использован репозиторий hello-docker, содержащий исходный код веб-приложения на языке Python с использованием фреймворка Flask.
Репозиторий был клонирован и использован в качестве основы для дальнейшей контейнеризации приложения.

### 3.3 Создание Dockerfile

Для контейнеризации веб-приложения был создан файл Dockerfile.
В качестве базового образа использовался официальный образ python:3.10-slim.

Dockerfile включает следующие этапы:

- задание базового образа;

- копирование файлов приложения в контейнер;

- установка зависимостей из файла requirements.txt;

- открытие порта 1234;

- запуск Flask-приложения.

### 3.6 Создание docker-compose.yml

Для развертывания веб-приложения совместно с базой данных PostgreSQL был создан файл docker-compose.yml.

В файле были описаны два сервиса:

сервис веб-приложения Flask;

сервис базы данных PostgreSQL.

Также были настроены переменные окружения, сетевое взаимодействие между контейнерами и проброс порта 1234.

### 3.7 Запуск стека контейнеров

Запуск приложения и базы данных был выполнен с использованием команды:

**docker-compose up**


В процессе запуска было подтверждено успешное подключение Flask-приложения к базе данных PostgreSQL.
